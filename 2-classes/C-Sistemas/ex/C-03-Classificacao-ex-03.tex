\begin{question}
  Sistema impossível

  Se uma linha tiver a forma
  \[
    \left(
    \begin{array}{rrr|r}
      0 & 0 & 0 & c
    \end{array}
    \right)
    \qquad c \neq 0
  \]

  \pause
  Não possui solução

  \pause
  Não importa os valores de $x$, $y$ ou $z$
  \[
    0x + 0y + 0y = 0 \neq c
  \]
\end{question}
